Política de privacidad

Última actualización: 6 de noviembre de 2026

Quién es el responsable

BunnyVid es una aplicación de escritorio creada y usada por Ulises de Alba Solis. Contacto: lifexbio@gmail.com.

Qué datos de Google usa la aplicación

Cuando el usuario conecta su canal, la aplicación solicita estos permisos de la API de YouTube:

  • youtube.upload: para subir videos al canal del usuario, con su título, descripción, etiquetas, portada y programación.
  • youtube.readonly: para leer el nombre y el identificador del canal conectado y poder mostrarlos al usuario.

Cómo se usan y dónde se guardan

  • Los datos se usan únicamente para subir videos al canal del propio usuario, a petición suya.
  • La autorización (token) se guarda solo en el ordenador del usuario, en un archivo local protegido. La aplicación no tiene servidor propio y no envía esos datos a ningún tercero.
  • No se venden, no se comparten, no se usan para publicidad ni para entrenar modelos de inteligencia artificial.
  • No se leen los videos existentes, los suscriptores, los comentarios ni las estadísticas del canal.

Cumplimiento

El uso que BunnyVid hace de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

Puedes revocar el acceso en cualquier momento desde myaccount.google.com/permissions, y borrando el archivo local de autorización de la aplicación. Al revocarlo, la aplicación deja de poder subir videos a tu canal.
